
# Praktikum 5 - JavaScript Dasar dan Manipulasi HTML

## Tujuan
Memahami dasar JavaScript, penggunaan function,
percabangan, perulangan, DOM, dan validasi input.

## Perangkat
- Visual Studio Code
- Browser
- HTML
- JavaScript

## Langkah Kerja
1. Membuat folder lab5_javascript.
2. Membuat file index.html dan script.js.
3. Menghubungkan JavaScript dengan HTML.
4. Mengerjakan Latihan 1 sampai Latihan 8.
5. Mengerjakan Mini Project Kalkulator Nilai Mahasiswa.
6. Mengerjakan eksperimen mandiri.
7. Menguji program dan mengambil screenshot hasilnya.

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka index.html menggunakan browser.
3. Jalankan setiap latihan sesuai petunjuk.
4. Buka Console browser jika diperlukan untuk melihat output.
